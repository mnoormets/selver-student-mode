# Selver Tudengirežiim

Häkatoni prototüüp: AI-abiga **tudengirežiim** Selveri ostmiseks. Ütle nädala eelarve ja eelistused — saad menüü, kampaaniakorvi ja jääkide-abilise.

## Mida proovida

1. **Lülita sisse** tudengirežiim
2. Sea eelarve (15–60 €), päevade arv ja stiil (odav / kiire / taimne / liha)
3. Vaata **menüüd**, **ostukorvi** ja küsi **abilt** nt „mul on 5 eurot“ või „kana jäägid“

Demo töötab ilma API-võtmeta (reeglipõhine planeerija + abiline, mock-hinnakataloog).

## Käivitamine

```bash
npm install
npm run dev
```

Ava [http://localhost:3847](http://localhost:3847).

## Idee lühidalt

Tudengitel on väike eelarve, vähe aega ja palju toidu raiskamist. Tudengirežiim paneb sama sibula mitmesse retsepti, eelistab Kirde oma kaubamärki ja kampaaniaid ning vastab kiiretele küsimustele („mida 5 euroga?“).
