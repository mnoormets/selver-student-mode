# Contributing

| Tool | Responsibilities |
| --- | --- |
| Claude Code | Architecture, planning, task generation, code review, and debugging guidance. |
| Codex | Implementation, refactoring, bug fixing, and test creation. |
| Cursor | Development assistance on Machine 2, including code navigation and debugging. Coordinate any edits with Codex first. |
| Lovable | UI generation only on either machine. Hand generated UI to Codex for integration. |

Keep each branch focused on one task. Use the acceptance criteria in `docs/current_task.md` to decide when the work is ready for review. Record architectural choices in `docs/decisions.md` and update `docs/roadmap.md` when an MVP feature ships.

See [Git Workflow](GIT_WORKFLOW.md) and [Hackathon Workflow](HACKATHON_WORKFLOW.md).
