# Roadmap

Deliver the [Selver Student Mode demo](mvp.md) in under three minutes. The [backlog](backlog.md) is the development queue.

| Hours | Exit condition |
| --- | --- |
| 0–6 | The offline week produces a verified basket and reuse summary. |
| 6–18 | The profile form and results work end to end with the reference week. |
| 18–30 | The live AI adapter proposes a week and invalid or over-budget plans are rejected. |
| 30–40 | The team verifies source labels and rehearses live and offline paths. |
| 40–48 | Fix demo blockers, capture a backup, and submit. |

If the provider is unavailable, present the labeled offline sample with the same basket calculations.
